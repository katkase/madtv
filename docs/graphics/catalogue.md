# Catalogue of the graphics files

*English · [Italiano](../it/grafica/catalogo.md)*

All graphics files of Mad TV v2.1 (Amiga), as found by the extractor. The
thumbnails come from `assets/`, generated locally with
`cargo run --release --example extract_assets` (see [README.md](README.md)).

"Loaded at" comes from Pam's five recordings in `scripts/registrazioni/`
(start-up = loaded before the first screen); a blank cell means the file was
not loaded in those sessions. Descriptions marked "(?)" are guesses from the
pictures.
