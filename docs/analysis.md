# Analysis of the original executables

*English · [Italiano](it/analisi.md)*

Results of the analysis carried out before starting the port, on two
versions: DOS (executables dated 10/2/1994) and Amiga ("Mad TV v2.1 (1991)",
Spanish version).

## Summary

The two versions come **from the same C sources**. On the PC they were
recompiled with Turbo C, and the Amiga-specific assembly parts were replaced
by external drivers.

| | Amiga | DOS |
|---|---|---|
| Game logic | C, **Aztec C (Manx)**, large model, 16-bit int | same sources, **Turbo C 2.0**, large model |
| Executable compression | Imploder | LZEXE 0.91 |
| Low-level graphics | blitter assembly, inside the executable | assembly in `MCV.BIN` (EGA bitplane driver) |
| Music | TFMX replayer in assembly (`098.HES`) | Palladix PSM driver (PC beeper, AdLib) in assembly |
| Data | `NNN.HES` files | `SOURCE1.RSC`, `SOURCE2.RSC`, `DATAV.PCK` (PowerPacker) |

Evidence of shared sources: the same printing routine with `#` instead of `%`
(`#02d:#02d`, `#_8l $`...), the German message `Fehler aufgetreten!`, the
character table `LQXWMNbOFJERD;<=>?@ABCG`.

## Amiga version

### Disks

- **Disk 1 (MTV1)**: startup-sequence `add21` / `rai` / `v u3.lbm` /
  `mtv s`. `mtv` is the game (141,556 bytes compressed).
- **Disk 2 (MTV2)**: 156 `NNN.HES` data files: text, graphics in a
  proprietary compressed format (63 files starting with `01 A0 6D`), 10 TFMX
  music modules (`TFMX-SONG`, with the samples in the following file) and the
  `098.HES` replayer.

### The `mtv` executable

- Compressed with **Imploder**: an initial mini-hunk walks the seglist and
  calls `explode`, which decompresses backwards into the BSS segments and
  applies the relocations; it then frees the decompressor's segments with
  `FreeMem` and jumps to the decompressed code.
- After decompression: 267,376 bytes of code + 42,072 bytes of data.
- **Aztec C start-up code**: `geta4` (`lea __H1_org+32766,a4`), BSS clearing,
  `__savsp`, `_SysBase`, FPU check (`btst #4,$129(a6)`), opening of
  `dos.library` with `Alert($38007)` on failure.
- 491 functions out of 586 start with `link a5` (compiled C); arguments on
  the stack, caller cleans up, 16-bit integers (`move.w`).
- About 9 KB of **hand-written assembly** for the blitter (minterm `$FCA`,
  cookie-cut), waiting with `btst #6,DMACONR` and one call per bitplane;
  parameters in registers.
- Hidden signature in the data: *"I hate C, but worse, AmigaOS and BCPL -
  Thomas B."*
- Official credits (`u3.lbm` screen): Project Manager Ralph Stock,
  Programming PC Stefan Hoffmann, Programming Christian Krämer, Graphics
  Thomas Andrae, Sound Rudi Stember.

### Runtime behaviour (from emulation, phase 1)

See NOTES.md: the game uses the operating system very little (only exec and
dos for memory and files), installs its own interrupt handler on `$6C` and
synchronises with a copper interrupt generated by its own copper list.

## DOS version

- `MTV.EXE`: C, **Turbo C 2.0** (string `Turbo-C - Copyright (c) 1988 Borland
  Intl.`), large model (all functions far, arguments from `[bp+6]`),
  compressed with **LZEXE 0.91**.
- The only direct hardware access in the executable: waiting for vertical
  retrace (port `$3DA`), in a small assembly module.
- `MCV.BIN`: binary graphics driver in assembly (11 entry points, EGA mode
  0Dh 320×200×16, bitplane writes through the map mask).
- `SOURCE1.RSC` contains the **Palladix PSM** sound drivers (.COM format):
  `V1.1 - PC-Beeper`, `V1.3 - AdLib (TM) soundcard`, `PALLADIX-PSMDETECT`.
- `INTRO.EXE`: Turbo C 1.5, small model.
- `DATAV.PCK`: compressed with PowerPacker (`PP20`), a format typical of the
  Amiga.

## Tools used

- Disassembler: Capstone (68000 and 16-bit x86), with recursive
  disassembly from the entry points and grouping by segment.
- Decompression: an LZEXE decompressor written for the occasion; for
  Imploder, running the original decompressor on an emulated 68000.
- Amiga file system: `amitools` (xdftool), then `src/adf.rs` in this project.
