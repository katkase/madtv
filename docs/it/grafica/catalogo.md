# Catalogo dei file di grafica

*[English](../../graphics/catalogue.md) · Italiano*

Tutti i file di grafica di Mad TV v2.1 (Amiga), come li trova l'estrattore.
Le miniature vengono da `assets/`, generata in locale con
`cargo run --release --example extract_assets` (vedi [README.md](README.md)).

"Caricato in" viene dalle cinque registrazioni di Pam in
`scripts/registrazioni/` (avvio = caricato prima della prima schermata); una
cella vuota significa che il file non è stato caricato in quelle sessioni. Le
descrizioni con "(?)" sono ipotesi ricavate dalle immagini.
